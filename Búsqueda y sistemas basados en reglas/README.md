# Entregable: Búsqueda y Sistemas Basados en Reglas

## Descripción del Proyecto
En este proyecto he escrito en Python las instrucciones para el desarrollo de un sistema inteligente que, a partir de una base de conocimiento escrita en reglas lógicas, desarrolle la mejor ruta para moverse desde un punto A hasta un punto B en el sistema de transporte masivo local.
